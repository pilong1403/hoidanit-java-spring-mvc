# Java Spring Laptop Shop (Code: SPRING-01)
update
## Summary
This is my personal project, the application is a server rendering e-commerce web designed to sell Laptop items. The project is built using Java Spring framework.

## Technologies
### Frontend
- **Frameworks/Libraries**: JSP, JSTL, jquery

### Backend
- **Frameworks/Libraries**: Java Spring boot 3.3.5

### Database
- MySQL

### Tools
- MySQL workbench

## Features
- **General**: User authentication (Login, Register, Confirm Email, Forgot Password), Profile Editing
- **Guest Users**: Browse products, Search with filters and pagination
- **Customers**: Add products to cart, Checkout with QR code
- **Sales Manager**: Payment management, Export monthly sales reports in XML format
- **Admin**: Product management
